# Pale Spectrum Access 1.0.0

First public release. Run **PaleSpectrumAccessInstaller.exe** to install, update or uninstall. Close the game first. You can still install by hand from the zip; see the README.

## What it does

- Reads dialogue, narration, choices (with whose choice it is), chapter titles and every menu through your screen reader, or Windows' voice if none is running.
- Makes the main menu, story picker, game menu, save and load, preferences, prompts, extras, credits, gallery and progress map usable from the keyboard.
- Describes all 103 gallery pictures and names all 26 endings.
- Reads a line that is only "..." as "ellipsis".
- F1 opens the accessibility settings; q opens the in-scene buttons (Rewind, Skip, Game menu).
- Tells you on the main menu when a newer version is out.
- Doesn't replace any of the game's files, and doesn't touch your saves.
